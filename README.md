# CookieTime Web MVP

**쿠키 타워가 기존 앱의 ‘기록’ 탭에 연결되었습니다.** 기존 집중 타이머와 시간표의 공강 판정으로 적립하고, 한국 시간 매월 1일에 새 타워를 시작하며 지난달 기록을 보관합니다. `node cookie-tower/server.cjs --app` 실행 후 `http://127.0.0.1:4173/`에서 확인할 수 있습니다. [적립·기존 기록 이전·검증 안내](cookie-tower/README.md).

기능명세서 버전 1의 MVP 흐름을 모바일 우선 웹으로 구현합니다. 디자인과 앱 동작을 분리해 디자인팀 시안과 캐릭터 교체가 쉽도록 구성했습니다.

## 실행

`index.html`을 브라우저에서 열거나 프로젝트 폴더에서 `python -m http.server 8000`을 실행하고 `http://localhost:8000`으로 접속합니다. 데이터는 브라우저 `localStorage`에 저장됩니다.

## 게스트 사용과 Google 로그인

앱은 회원가입 없이 사용할 수 있습니다. 로그인은 Google 계정을 사용하며 Firebase Authentication 설정이 있어야 활성화됩니다.

1. Firebase Console에서 웹 앱을 추가하고 Authentication의 Google 제공업체를 사용 설정합니다.
2. `auth-config.js`의 `apiKey`, `authDomain`, `projectId`, `appId`를 해당 웹 앱 설정으로 채웁니다. 이 웹 설정은 공개 식별 정보이므로 데이터베이스 접근 규칙을 별도로 보호해야 합니다.
3. Firebase Authentication의 승인 도메인에 배포 도메인(예: `songchaewonn.github.io`)을 추가합니다.
4. HTTPS로 제공되는 웹 앱에서 Google 로그인을 사용할 수 있습니다. 로컬 파일(`file://`)로 열면 OAuth 로그인이 동작하지 않을 수 있습니다.

로그인 후에도 현재 앱 데이터는 기존처럼 각 기기의 `localStorage`에 남습니다. 이 버전은 계정 인증만 제공하고 클라우드 백업·기기 간 동기화는 하지 않습니다. 실제 인증은 Firebase 프로젝트 설정을 입력한 뒤 확인해야 합니다.

공강 솔루션은 시간표 사이의 10분 이상인 남은 시간을 길이에 따라 복습·암기, 과제 일부 진행, 과제 집중/휴식으로 제안합니다. 미완료 과제를 우선 제시하며, 수락하면 해당 시간에 시작 알림이 예약됩니다.

## 포함 기능

- 주간 시간표 입력과 수업 수정·삭제, 겹치는 시간 검사, 설정 가능한 공강 기준
- 과제 등록·수정·삭제·메모, 마감일/중요도 정렬, 마감 1일 전·3시간 전 알림
- 과제 시작 카운트다운 간격 설정, 정각의 집중 시작/5분 미루기(최대 2회)
- 첫 실행 권한 안내, 집중·쉬는 시간 분리 타이머, 방해 앱 적용 기준(집중 중/항상/요일·시간), 진동 단계·강도·방해금지 설정
- 미션 퀴즈와 인지 유연성 미니 게임, 포인트 없는 일일 스트릭과 월간 달력, 주간 집중·앱 이탈·정시 시작률 통계
- 시간표 이미지 한국어 OCR 초안과 수업별 수동 검토·저장, 수업 종료 시 할 일 빠른 추가
- Android 오버레이의 사용시간 선택과 시간 종료 동작, 위치 저장·화면 가장자리 스냅
- Uno + HC-06 하드웨어 LCD 연결: 데스크톱 Web Serial 및 Android 앱 Bluetooth SPP

## Uno + HC-06 하드웨어 연결

배선과 Arduino 스케치는 `hardware/README.md` 및 `hardware/cookietime_uno/cookietime_uno.ino`를 참고하세요. 웹 앱은 데스크톱 Chrome/Edge에서, Android 앱은 집중 화면의 `LCD 타이머 연결` 버튼에서 HC-06을 선택해 연결합니다. LCD에는 앱의 연속 집중 시간과 집중/휴식/대기 상태가 표시됩니다. 실제 보드 연결은 장치에서 확인해야 합니다.

웹 버전은 탭이 실행 중일 때 화면 내 안내를 제공하며, 브라우저 탭이 닫힌 뒤의 알림은 보장하지 않습니다. Android의 시스템 알림, 설치 앱 감지와 오버레이는 별도 Android 프로젝트에서 구현합니다.

## 디자인 교체

- 디자인 토큰과 레이아웃은 `styles.css`에 있습니다.
- 캐릭터는 `public/assets/cookie-character.png` 한 파일로 교체할 수 있습니다.
- 화면 렌더링과 데이터 저장 로직은 `app.js`에서 구분합니다.

## 범위와 제한

BLE/ESP32 실제 연결과 친구 추가·경쟁 기능은 현재 범위에서 제외했습니다. 로그인은 게스트 우선이며 Google 인증은 Firebase 설정 후 웹 브라우저에서만 켤 수 있습니다. 계정 동기화와 클라우드 백업은 제공하지 않습니다. 시간표 OCR 엔진은 첫 사용 시 내려받으므로 네트워크가 필요할 수 있고, 표 인식 정확도에 따라 인식 결과와 각 수업의 요일·시간을 직접 검토해야 합니다. 웹 브라우저에서는 수업 종료 알림이 앱을 열어둔 동안에만 동작합니다.
