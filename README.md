# CookieTime MVP

기능명세서 v0.1의 MVP 범위(P0)를 바탕으로 만든 모바일 우선 화면/동작 프로토타입입니다. UI와 저장 계층을 단순한 파일 구조로 분리해 향후 디자인 시안과 Android 구현으로 옮기기 쉽게 구성했습니다.

## 실행

`index.html`을 브라우저에서 열면 동작합니다. 로컬 개발 서버를 쓰고 싶다면 프로젝트 폴더에서 `python -m http.server 8000`을 실행한 뒤 `http://localhost:8000`으로 접속하세요. 모든 프로토타입 데이터는 브라우저 `localStorage`에 저장됩니다.

## 현재 동작하는 흐름

- 홈: 오늘 일정, 할 일, 공강 요약과 빠른 메뉴
- 시간표: 주간 날짜 이동, 요일별 수업 조회, 수업 추가, 수업 사이 공강 표시
- 할 일: 마감일 순 정렬, 예상 시간/중요도/메모, 완료 및 삭제
- 집중: 집중 세션 타이머, 수동 이탈 시작/복귀와 이탈 기록, 지원 기기의 진동 API 사용
- 설정: 알림·캐릭터·진동 토글, 방해 앱 선택, 권한 안내 진입점
- 시작 예정 시간이 10/5/3/1분 전 및 정각에 가까워지면 화면 내 예고를 띄웁니다. 브라우저 탭이 닫혀 있거나 백그라운드 제한이 적용되면 알림 시각을 보장하지 않습니다.

## 교체하기 쉬운 부분

- 색, 둥근 모서리, 그림자, 글꼴은 `styles.css` 맨 위의 CSS 변수로 모았습니다.
- 캐릭터는 전달받은 초안 이미지에서 쿠키 캐릭터를 그대로 분리한 `public/assets/cookie-character.png`입니다. 다시 그리거나 스타일을 바꾸지 않았으며, 디자인팀 확정 시 이 파일만 교체하면 화면 코드를 바꾸지 않아도 됩니다.
- 화면과 동작은 `app.js`의 페이지 렌더 함수와 이벤트 처리로 나눴습니다. 영구 저장은 `save()`/`loadState()`를 한 곳에서 다룹니다.
- MVP 이후 OCR, 공강 추천, 미션/포인트, 통계, 로그인과 친구 기능은 추가하지 않았습니다.

## Android MVP

`android/`에 기존 웹 화면을 앱 패키지에 자동 포함하는 Android Studio 프로젝트를 추가했습니다. WebView는 화면을 재사용하고, JavaScript bridge와 네이티브 서비스가 앱 목록·사용 감지·캐릭터 오버레이·진동·시작 알림을 연결합니다. 여는 방법과 권한 설정은 [Android MVP 안내](android/README.md)를 참고하세요.

시간표와 할 일은 WebView의 기기 내 저장소를 사용하고, 금지 앱 목록과 감지 기록은 Android 기기에 저장합니다. Android 전용 기능은 제조사와 OS 버전별 실기기 점검이 필요합니다.
