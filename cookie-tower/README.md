# 차곡 · 쿠키 타워

모바일 우선 쿠키 타워와 기존 앱에 연결하는 모듈입니다. 기존 앱에서는 ‘기록’ 탭에서 타워를 보고 기존 집중 타이머·시간표를 사용합니다. 별도 미리보기에서는 첨부 시안의 390×915 화면과 체험 패널을 확인할 수 있습니다. 타워 자체는 외부 패키지나 네트워크가 필요하지 않습니다.

## 기존 앱에서 사용

프로젝트 루트에서 `node cookie-tower/server.cjs --app` 실행 후 http://127.0.0.1:4173/ 에 접속하세요. 이 폴더에서는 `npm run start:app`으로 실행할 수 있습니다. 앱의 **기록** 탭이 새 타워입니다.

- 기존 앱의 스톱워치·집중 타이머가 유일한 적립 소스입니다. 시간표에서 한 시간을 완성한 시각의 공강 여부를 자동 판정합니다.
- 집중 중 ‘타워 보기’로 이동하고 다시 집중 화면으로 돌아갈 수 있습니다. 기록 화면을 보고 있어도 정해 둔 집중 타이머는 끝납니다. 늦게 도착한 브라우저 tick은 설정 시간을 초과하여 적립하지 않습니다.
- 휴식하면 쿠키 보상의 연속 시간은 0부터 새로 시작합니다. 오븐의 ‘이번 집중 시간’은 해당 세션 전체의 순수 집중 시간이고, 그 아래의 ‘연속 집중’은 휴식 후 초기화되는 보상 기준 시간입니다.
- 한 시간 미만은 쿠키를 지급하지 않습니다. ‘쿠키 꺼내기’는 기록 화면을 여는 동작이며, 추가 보상을 중복 지급하지 않습니다.
- 타워 오른쪽 위의 `N월 · 쿠키 N개` 버튼에서 월별 기록을 열고, 과거의 타워를 다시 보거나 JSON으로 내보냅니다. 기존 집중 통계·스트릭 달력도 그대로 열 수 있습니다. MY에서도 월별 기록에 접근합니다.
- `tower-integration.js`가 기존 앱의 `state.cookieTower`에 월별 장부를 저장하고, `cookieRewards`의 수량을 이번 달 쿠키 수로 맞춥니다. 두 데이터는 기존 `save()`에서 하나의 `cookietime-mvp-v1` 저장값으로 함께 기록합니다. 독립 미리보기의 저장값을 합산하지 않습니다.
- 첫 연결 때 기존 보유 쿠키를 한 번만 옮깁니다. 날짜가 있는 기존 적립은 해당 월에 보관합니다. 과거 버전에서 내역을 30개만 보관했으므로 날짜를 알 수 없는 나머지 보유량은 **연결한 달에 포함**하고 월별 기록에 안내합니다. 원본 보상 데이터는 `state.cookieTower.migration.originalRewards`에 보존합니다.
- 연결 당시 진행 중인 집중의 이미 지급된 시간은 다시 적립하지 않으며, 남은 시간과 연속 등급은 이어받습니다.

`tower-app.js`와 `tower-app.css`가 기존 앱용 화면입니다. `tower-core.js`와 `tower-art.js`는 두 화면에서 함께 사용합니다. APK에 패키징하는 별도 Android 프로젝트가 있다면 변경된 웹 파일과 `cookie-tower` 디렉터리를 함께 포함해야 합니다.

## 독립 미리보기 실행

이 폴더에서 `npm start` 후 http://127.0.0.1:4173/cookie-tower/ 에 접속하세요. 또는 프로젝트 루트에서 `node cookie-tower/server.cjs`를 실행하세요. `index.html`을 직접 열어도 화면은 작동하지만, 안정적인 기록 저장·이미지 다운로드를 위해 로컬 서버를 권장합니다.

첫 화면은 시안과 비교할 수 있는 **540m 미리보기**입니다. **내 타워**를 누르면 실제 기록을 표시합니다. 미리보기의 쿠키는 저장하거나 실제 기록에 더하지 않습니다. 기존 앱의 데이터도 읽거나 바꾸지 않습니다.

## 구현된 동작

- 완성한 연속 집중 1시간마다 1개, 공강이면 2개. 다섯 번째 완료 시간부터 시간당 5개이며 공강 보너스는 중복하지 않습니다. 예: 기본 6시간 = `1+1+1+1+5+5 = 14개`, 공강 6시간 = `2+2+2+2+5+5 = 18개`.
- 집중을 마치거나 쉬면 연속 시간이 초기화됩니다. 1시간 미만은 쿠키를 지급하지 않으며 다음 세션으로 이월하지 않습니다. 이미 받은 쿠키는 보존합니다.
- 쿠키 1개당 **10m**. `tower-core.js`의 `HEIGHT_PER_COOKIE`가 기준입니다.
- **0m 숲속 / 100m 산 정상 / 1,000m 구름 위 / 10,000m 우주**. 우주 기준은 이미지 속 6,500m 대신 사용자가 요청한 10,000m를 적용했습니다.
- 적립 시 쿠키가 떨어져 내려와 튕기며 쌓이는 모션. 한 번에 여러 개를 받으면 순서대로 떨어집니다. 모션 줄이기 설정도 지원합니다.
- 많은 쿠키는 최근 6~12개를 대표로 그립니다. 실제 총 쿠키 수와 고도는 전체 적립량을 사용합니다.
- **Asia/Seoul 기준 매월 1일 00:00**부터 새 달의 타워를 사용합니다. 앱이 꺼져 있으면 다음 실행 때 반영합니다. 이전 달은 삭제하지 않고 월별 쿠키 수·집중 시간·최장 연속 시간·공강 보너스 기록을 보존합니다.
- 월 경계를 넘는 집중 시간은 달별로 나누고, 쿠키는 한 시간을 완성한 시각의 달에 적립합니다. 연속 집중 등급은 월 경계에서 끊지 않습니다.
- 기록 메뉴에서 지난달 타워를 다시 볼 수 있습니다. 미래나 임의의 과거 기록을 샘플로 저장하지 않습니다.
- 780×1830 PNG 이미지 다운로드, 지원 기기에서는 파일 공유. 미리보기 이미지는 미리보기라고 표시합니다.
- MY에서 전체 기록을 JSON으로 내보낼 수 있습니다.

## 화면 메뉴

- 홈: 독립 집중 타이머. 공강 여부를 선택하고 집중을 시작하거나 마칩니다.
- 시간표: 공강 적립 설명 및 공강 집중 진입. 현재는 직접 공강 여부를 선택합니다.
- 기록: 이번 달 요약과 지난달 기록. 지난달을 누르면 보관된 타워를 표시합니다.
- MY: 저장 상태, 월 갱신 기준, 기록 내보내기.
- 상단 `미리보기` / `N월의 타워`: 모바일에서도 미리보기와 실제 타워를 전환합니다.
- 풍경 배지: 모든 고도 배경 미리보기.

## 기존 앱 연결 API

화면과 독립적인 `tower-core.js`를 기존 앱에서 재사용할 수 있습니다. 전역 `CookieTowerCore`로 제공하며 Node에서는 `require()`도 지원합니다. 저장 키는 `chagok-cookie-tower-v1`입니다.

```js
const tower = CookieTowerCore.createStore();

// 같은 연속 집중 세션에서는 고정 ID, totalSeconds는 누적 초입니다.
// at은 이 누적 초를 관측한 시각입니다. 처음 연결할 때 과거 시간을
// 임의로 소급하지 말고, 연결하기로 한 시작점부터 누적하세요.
const result = tower.syncSession({
  sessionId: 'focus-session-unique-id',
  totalSeconds: 3600,
  isGap: true,
  at: Date.now()
});
console.log(result.result.cookies); // 2

// 휴식 또는 집중 종료 후에는 새 sessionId를 사용합니다.
tower.endSession('focus-session-unique-id');
console.log(tower.summary());
console.log(tower.history());
```

타워 화면 안에서는 `window.CookieTower.recordFocus(...)`, `getSummary()`, `getHistory()`, `endSession(id)`, `showMyTower()`로 같은 기능에 접근할 수 있습니다. `recordFocus` 후 `cookie-tower:updated` 이벤트를 전달합니다.

같은 ID와 누적 초를 다시 전달해도 중복 적립하지 않습니다. 더 오래된 스냅샷이나 종료된 세션도 다시 지급하지 않습니다. `isGap`은 **각 한 시간을 완성한 시각의 공강 여부**입니다. 기존 시간표에 연결하여 한 번에 과거 여러 시간을 복구할 때 공강 여부가 바뀌었다면 각 시간 경계의 스냅샷을 순서대로 전달하세요. 실시간 연결에서는 현재 시간표의 공강 판정을 전달하면 됩니다.

실제 앱 타이머를 연결할 때 이 화면의 독립 타이머와 동시에 실행하지 마세요. 같은 집중을 두 번 적립하지 않도록 한 타이머만 적립 소스로 사용해야 합니다.

## 저장 및 검증

`npm test`로 20개 검증을 실행합니다. 적립률, 5시간 등급, 중복 방지, 새로고침 복구, 휴식, 한국 시간 월말·연말 전환, 경계 시각의 적립과 배경 임계값뿐 아니라 기존 잔액의 일회성 이전, 공강 시각별 보너스, 실제 `app.js`의 시작·pulse·휴식·종료·저장, 다른 화면에서의 타이머 종료를 확인합니다.

저장은 이 기기의 브라우저 `localStorage`에 한정됩니다. 서버나 계정 동기화는 아직 연결하지 않았습니다. 타이머는 시작 시각을 보관하여 새로고침·탭 재접속 때 따라잡습니다. 브라우저가 닫힌 동안 실제로 집중했는지 판정하는 기능은 기존 앱의 집중 감지와 연결해야 합니다. 독립 타이머는 사용자가 집중 종료를 누를 때까지 경과 시간을 집중으로 계산합니다.
